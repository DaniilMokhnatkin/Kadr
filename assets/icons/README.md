# Kadr — знак кадра

Четыре уголка выделения: один и тот же силуэт в приложении, файле exe и трее. Направление
awesome-claude-design / editorial / Vercel grayscale; без текста внутри знака, цветного акцента,
градиентов, теней или мелких дополнительных символов.

- `kadr.svg`, `kadr.ico`, `kadr.png` — знак на плоской тёмной плитке для приложения/Explorer.
- `tray-dark.*` — белый знак на прозрачном фоне для тёмной панели.
- `tray-light.*` — тёмный знак на прозрачном фоне для светлой панели.
- `review.png` — исходный масштаб 16/20/24/32/40/48 и увеличенная пиксельная сетка 16 px.
- Каждый ICO содержит 16/20/24/32/40/48/64/128/256 px. Малые варианты трея построены по физической
  сетке, а не уменьшением 256 px. Толщина основных штрихов в размере 16 — 2 px.

Проверка ui-ux-pro-max: контраст основных непрозрачных штрихов #fff/#111 ≈ 18,9:1,
#111/#f0f0f0 ≈ 16,6:1. Силуэт не зависит от цвета, подпись Kadr остаётся в системной подсказке
трея; SVG имеет текстовую альтернативу. Для высокой контрастности Windows выбирается чёрная или
белая версия с учётом системного фона. Размер области клика определяет оболочка Windows, не ICO.

Полировка taste-skill: проверены реальные малые размеры на обеих поверхностях, интервалы и
внутренний просвет; убраны пересечения подписей на листе проверки. Browser/DOM-инспектор к
встроенному нативному ICO неприменим. Дополнительно проверены все 27 PNG-кадров внутри ресурсов
готового exe и загрузка каждого размера Win32 LoadImageW без запуска приложения.

`kadr.rc` задаёт ресурс 1 для приложения, 101/102 для трея. Cargo вызывает установленный Windows
SDK rc.exe; для другого размещения компилятора можно задать переменную RC. Генератор ассетов
запускается отдельно: `python assets/icons/build_icons.py` (Pillow), при обычной сборке Python не нужен.
