# M2 — редактор на месте

Опирается на ARCHITECTURE.md §7–9 и §15. Реализуем в существующих крейтах без нового UI-фреймворка.

| Слой | Ответственность | Проверка |
|---|---|---|
| kadr-doc | сериализуемые фигуры, геометрия, ограничение данных, матовое размытие | unit, повреждённые данные, одинаковый seed |
| kadr-editor | инструменты, предварительный штрих, выбор/перенос/размер, текст, undo/redo | последовательности пользовательского ввода |
| kadr-render | единая отрисовка аннотаций в D2D и в экспортную поверхность | offscreen PNG, сравнение пикселей |
| kadr-app/store | панель, ввод Unicode, буфер/PNG, черновики | интеграционные тесты и сборка |

Инструменты: выбор, стрелка, линия, прямоугольник, эллипс, перо, маркер, текст, счётчик,
размытие прямоугольником/овалом/кистью/всё кроме, сплошное скрытие. Цвет и толщина, три силы размытия.
Рисуем внутри выделения; новый штрих — одна операция истории, текст — одна операция, перемещение — одна.
Esc отменяет незавершённый ввод, затем выходит из инструмента, затем закрывает снимок.

Модель хранит фигуры в зашифрованном state.enc. Старые черновики без фигур открываются.
При смене мониторов координаты аннотаций преобразуются вместе с выделением.
И экран, и PNG/буфер используют один draw_annotations; элементы интерфейса в экспорт не попадают.

Размытие уменьшает область в крупные блоки, добавляет шум с криптографическим seed и плавно увеличивает.
Оно теряет мелкие детали, но не считается доказанной защитой коротких секретов. Сплошное скрытие
не зависит от исходных пикселей. Превью/экспорт детерминированы для одной фигуры и seed; оригинал остаётся
только в зашифрованном локальном черновике. При отказе рендера экспорт прерывается, исходник не выдаётся.

Проверки: cargo test --workspace; cargo clippy --workspace --all-targets -- -D warnings;
cargo build --release. Нативные проверки запускаются в обычном Windows-окружении. Установка uiAccess отдельно.

`tools/check-m2.ps1` проверяет редактор без ввода в рабочий стол: реальные Drawing / Direct2D / PNG / DPAPI,
синтетические кадры, сохранение и восстановление. Отдельный сценарий сравнивает экранную сцену с экспортом;
для GPU-сглаживания допустим ±1 в цветном 8-битном канале, скрытие — строго одинаковое на разных исходниках.
Эта проверка не подменяет тест доставки событий от Windows и не меняет системный буфер обмена.

От исходного расширенного §9 намеренно не принимается обещание необратимости размытия коротких секретов.
В первой реализации фиксированы блоки 16/24/40 px, увеличение билинейное; нет OCR-оценки высоты строки
и отдельного GPU Gaussian-прохода. Для защиты секретов предусмотрено сплошное скрытие. См. STATUS.md.
