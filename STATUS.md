# Kadr — состояние проекта, 30 октября 2026

## Умное размытие, длинный снимок, тёмная тема, подсказки

- **«Скрыть данные»** — заметная кнопка рядом с «Копировать». Локальный OCR со словами →
  `sensitive.rs`: почта, телефоны, карты (Луна), IPv4, IBAN (контрольная сумма), ключи/токены;
  даты, версии, пути и ссылки не трогаются. Пока идёт поиск, по выделению и кнопке пробегает
  полоса света; найденное проявляется размытием по порядку чтения с акцентной обводкой; повторное
  нажатие растворяет обратно и убирает только эти размытия. Добавление и снятие — по одному шагу отмены.
- **Длинный снимок** — кнопка на панели или колесо вниз внутри рамки (до рисования). Оверлей уходит,
  остаётся «дышащая» рамка (клики и колесо проходят насквозь) и панель «высота · Отмена · Готово»,
  Enter/Esc. Кадры ~15/с склеиваются по отпечаткам строк (`kadr_doc::stitch`): шапка и подвал —
  один раз, полоса прокрутки игнорируется, прокрутка назад не дублирует строки. Результат — в буфер
  и в миниатюру.
- **Подсказки** вверху экрана: «Alt + клик — перевод» без выделения, «Колесо внутри рамки — длинный
  снимок» после выделения; смена подсказки — через исчезновение и появление.
- **Тёмная тема** по настройке Windows «режим приложений»: панель, «Недавние», «Настройки», пузырь;
  DWM получает тёмный материал. Контраст проверяется тестом для обеих тем.
  `KADR_APPEARANCE=dark|light` — для снимков дизайна.
- Тесты: 124. Установка uiAccess-сборки — `installer\install.ps1` от администратора (запускает пользователь).

## Окна, миниатюра, текст с экрана

- **Цвет и толщина** применяются к печатаемому тексту, выделенной фигуре или только что нарисованной;
  смена инструмента — новая фигура. Набор текста вместе со стилем — один шаг отмены.
- **«Недавние»** — одна поверхность Direct2D на акриле Windows 11 (`glass.rs` — общая основа окон):
  без GDI и дочерних кнопок, поэтому не мигает. Карточки въезжают каскадом, приподнимаются при
  наведении; кольцо фокуса скользит; «Очистить» подтверждается на месте (красная, 3.5 с).
- **Миниатюра после снимка** (`thumbnail.rs`): справа снизу монитора снимка, 5 с, наведение держит.
  Перетаскивание отдаёт настоящий PNG через drag-источник оболочки (чаты, браузер, Проводник);
  свайп вправо или × — убрать; клик — вернуться в редактор (несохранённый) или к файлу (сохранённый).
  Скрывается перед следующим захватом. `[save] thumbnail = false` выключает.
- **Текст с экрана**: распознавание — встроенный Windows OCR (локально, en-US и ru, берётся более
  богатое чтение). Alt+клик по абзацу в оверлее — перевод этого абзаца; на панели «Скопировать текст»
  (Ctrl+Shift+C) и «Перевести» (Ctrl+T). Размытие применяется до распознавания: размытый текст не
  читается и не отправляется. Перевод — открытый адрес Google `translate_a/single` без ключа, POST:
  уходит только распознанный текст. Результат — акриловый «пузырь» рядом с текстом с кнопкой копирования.
- **Настройки** (`settings_window.rs`, из трея): переключатели (автозапуск через `HKCU\…\Run\Kadr`,
  миниатюра, уведомления, «Недавние», мгновенный захват), папка через системный выбор, хоткеи —
  клик и новое сочетание (глобальные хоткеи на это время снимаются). Изменения пишутся в
  config.toml (`config::render` повторяет шаблон с комментариями) и применяются наблюдателем файла.
- Тесты: 113. Три теста скрытых окон проверяют, что фокус не уходит; создание окон теперь с
  `SWP_NOACTIVATE`. Живая проверка акрила, перетаскивания в чаты и перевода на экране — за пользователем.

## Движение и материал в духе macOS

Пользователь: анимации «дешёвые», нет плавности macOS. Причины: у всех свойств была одна критически
демпфированная пружина без веса, выбор переливался между кнопками вместо скольжения, панель была плоской
непрозрачной карточкой, экран затемнялся мгновенно.

- Пружины по модели SwiftUI (`response`, `damping`) с аналитическим решением, в том числе недодемпфированным:
  геометрия 0.40 с / 0.86, появление 0.36 с / 0.76 (мягкий «поп» ~2.5 %), скольжение 0.34 с / 0.80.
  Hover загорается за 0.08 с и гаснет за 0.30 с. Поза не зависит от частоты кадров.
- Панель вырастает из края выделения: масштаб 0.94 → 1, подъём 8 px, прозрачность. Hit-test учитывает это преобразование.
- Одна «таблетка» выбора скользит между инструментами, цвет значка следует за ней; кольцо цвета скользит между образцами.
- Смена параметров — каскад: старые уходят за 0.075 с, новые въезжают по одному с шагом 14 мс. Ряд не
  показывает обрезки, пока открыт меньше чем на 40 %.
- Подсказки — после 0.5 с покоя курсора; при переходе к соседней кнопке сразу.
- Материал панели — размытый скрин (Gaussian blur D2D, σ 20 DIP) + затемнение + светлый тинт 84 %, мягкая
  тень из колец, волосяная граница и светлый внутренний кант. В высокой контрастности — непрозрачно, без тени.
- Затемнение экрана появляется за ~0.15 с; подсветка окна при выборе скользит между окнами.
- Уход оверлея (0.2 с): после «Копировать»/«Сохранить» буфер и файл готовы сразу, затем панель сжимается
  и гаснет, затемнение, рамка и пометки растворяются, выделение один раз мягко вспыхивает. Последний кадр —
  чистый экран, поэтому скрытие окон незаметно. Esc/«Закрыть» — то же без вспышки; Esc во время ухода
  завершает его сразу, ввод в это время игнорируется. «Сохранить как…» открывает диалог после ухода.
  Позы проверяются через `kadr --editor-snapshot файл.png --exit 0.6`.
- Размытие: средние по ячейкам на случайной сетке, монохромный шум (без цветных пятен), сглаживание
  кубическим B-сплайном (без квадратов), лёгкий подъём насыщенности и зерно, растушёвка края наружу —
  внутри фигуры исходных пикселей нет. Краевые ячейки усредняют полное окно k×k. По умолчанию — мягкая сила.
  Кисть размытия: ~6.8 мс на кадр в `--interaction-bench` против ~5.6 мс у прежнего алгоритма.
- `--motion-bench` рисует цветной фон; со стеклом p95 ≈ 1.0 мс при бюджете 5.88 мс (170 Гц).
  Это синтетика CPU+GPU, не развёртка на экране. Живое ощущение проверяет пользователь.

## Переходы и частота кадров

После замечания пользователя добавлены плавное раскрытие панели и её параметров, переходы
подсветки и tooltip. Панель больше не исчезает при начале штриха. DXGI продолжает запрашивать
кадры, пока есть активная анимация, без таймера на 60 FPS; нативный hover обновляется по частоте
монитора окна. Уважаются системное отключение анимаций и высокая контрастность. Подробности
и границы замеров — MOTION.md. Фоновый набор: 96 тестов.

## Дизайн Porcelain

Переработаны панель редактора, «Недавние» и Pin: светлые поверхности, единая outline-семья,
контекстные параметры и одно главное действие. Вместо 14 текстовых инструментов сразу — 11 пиктограмм;
разновидности размытия раскрываются в своей группе. Панель 544×112/160 DIP в обычной ширине,
на узкой поверхности переносится. Pin получил тихую строку управления, галерея — крупные превью.
Подробности, токены, доступность и пределы проверки — DESIGN.md. Все инструменты/хоткеи сохранены.
Плавность предыдущей версии пользователь подтвердил. Итоговые 90 фоновых тестов, Clippy и release
прошли; контрольный экспорт совпал с версией до редизайна пиксель в пиксель.

## Исправление плавности

После жалобы на рваные кисти исправлены координаты событий и восстановление промежуточных точек мыши.
Отрисовка больше не выполняется синхронно на каждое движение: у мониторов независимая готовность DXGI,
а ввод продолжает обрабатываться во время ожидания. Кэшированы layouts панели и общий CPU-композит размытия.
Пиксельный алгоритм размытия сохранён; неудачные эксперименты с интерполяцией откачены.
Подробности, замеры и ограничения — PERFORMANCE.md. Offscreen-проверки не измеряют физический FPS монитора.
Итог: 84 фоновых теста, Clippy с `-D warnings` и release прошли. Контрольный чистый PNG новой версии
совпал со старым побайтно по пикселям; настоящий Present(1, DO_NOT_WAIT) проверен на скрытом окне без смены фокуса.

## M3: закрепление и переход в «Недавние»

- «Закрепить» / Ctrl+D открывает готовый снимок поверх окон. В нём уже есть все аннотации и скрытия.
  До 20 окон одновременно; закрытие окна не удаляет локальный черновик.
- Масштаб: колесо, +/− и кнопка с процентом (сброс). Размер ограничен рабочей областью монитора.
  Прозрачность: Ctrl+колесо или «Видимость», 30–100 %. Копирование всегда отдаёт исходный плоский
  результат в полном разрешении, независимо от масштаба и прозрачности окна.
- Перенос за изображение/заголовок или стрелками (Shift — 10 px). Ctrl+C — копировать,
  Escape / двойной клик / «Закрыть» — закрыть окно. Tab и Enter работают с нативными кнопками.
- «Недавние» / Ctrl+H открываются прямо из панели скриншота. «К снимку» или Escape возвращают
  текущую рамку, аннотации и историю отмен. Выбор другого кадра открывает его; при включённом
  автосохранении прежний остаётся в зашифрованных черновиках. Незаконченный видимый штрих фиксируется.
- Действия панели разделены на две строки: экспорт и работа со снимками. Стиль — editorial / Vercel
  grayscale; цвет остаётся у изображения. Pin использует нативные кнопки с доступными именами и фокусом.
- Фоновая проверка теперь `powershell -File tools/check.ps1`; старый check-m2.ps1 вызывает её же.
  Тесты создают только скрытые окна, посылают сообщения только им и проверяют, что фокус не сменился.
  Нет SendInput, показа окон, захвата рабочего стола и изменения буфера обмена. Есть offscreen PNG
  при 100/150/200 %, проверка попадания в кнопки, возврата к редактору и освобождения окон.

Эта часть M3 не включает перенос в чаты, окно настроек и доводку установщика — это следующие части.
Проверка первой части M3: 76 фоновых тестов прошли, Clippy с `-D warnings` прошёл, release собран.
Также исправлен кратковременный OS error 145 при удалении уже пустого каталога черновика:
ограниченные повторы не удаляют посторонние файлы и не скрывают постоянную ошибку.
Новая uiAccess-установка не выполнялась. Нативные сообщения и рендер проверены автоматически;
перенос между реальными мониторами с разным DPI и поведение поверх повышенных окон остаются живыми проверками.

M2 реализован: редактор поверх выделения, аннотации, текст, четыре формы размытия, палитра и история.
Программа собрана; автоматические проверки контроллера, Direct2D, экспорта и восстановления проходят.
Живой проход мышью остановлен пользователем через физический Escape; матрица DPI/мониторов остаётся открытой.

## Редактор M2

- Выбор V, стрелка A, линия L, рамка R, овал O, перо P, маркер M, текст T, счётчик N.
- Размытие прямоугольником B, овалом E, кистью U, «всё кроме» I; три силы. Сплошное скрытие X.
- Выбор и перенос фигур, восемь маркеров размера, Del, стрелки (Shift — 10 px), Ctrl+Z / Ctrl+Y.
- Шесть цветов (1–6), толщина кнопкой, колесом или [ / ]. Колесо у размытия меняет силу.
  Tab / Shift+Tab перебирают инструменты. Shift выравнивает линию или задаёт квадрат/круг.
- Текст Unicode: каретка, выделение Shift+стрелки и Ctrl+A, вставка/копирование/вырезание,
  Backspace/Del, Home/End; F2 или двойной клик в режиме выбора — правка.
  Enter завершает текст, Shift+Enter добавляет строку. Следующий Enter копирует снимок.
- Esc отменяет текущий штрих/ввод, затем снимает выбор фигуры и выходит из инструмента;
  в режиме выбора без выбранной фигуры — закрывает снимок.
- PNG и буфер используют один рендер аннотаций; UI не экспортируется. При ошибке рендера исходник не выдаётся.
- Фигуры и seed хранятся в зашифрованном state.enc; старые черновики совместимы.
  Превью «Недавних» тоже содержит правки. При смене раскладки фигуры переводятся вместе с кадром.
- История: до 80 операций за текущую сессию; после восстановления начинается заново.
  Лимиты документа: 256 фигур, 65 536 точек суммарно, 8192 точки в одном штрихе, 4096 байт текста в фигуре.

Размытие — визуальное скрытие деталей: уменьшение по блокам, шум, плавное увеличение.
Тест потери деталей не доказывает защиту PIN/паролей от подбора. Для секретов используйте «Скрыть»:
его плоские пиксели не зависят от исходника. Оригинал для редактирования остаётся в локальном DPAPI-черновике.

## Проверка без перехвата управления

`powershell -File tools/check-m2.ps1` запускает тесты контроллера, offscreen Direct2D, PNG, хранилища и DPAPI,
затем Clippy. Ни резидентный Kadr, ни SendInput, ни глобальные хоткеи, ни системный буфер тесту не нужны.
Синтетический кадр заменяет снимок рабочего стола. PNG сценария и result.txt появляются в target/m2-check;
другую папку задаёт `-Artifacts`. Нужен доступ к обычному Windows GPU/DPAPI, но курсор и фокус не меняются.
Реальную доставку событий мыши Windows этот сценарий не подтверждает.

Итог этой итерации: 66 тестов фонового сценария прошли, Clippy с `-D warnings` прошёл,
release собран, 27 встроенных кадров иконок проверены (по 9 у приложения и двух вариантов трея).
Ранее полный workspace также прошёл проверку настоящего clipboard; фоновой скрипт её исключает,
чтобы не менять буфер пользователя. Регрессионный тест дополнительно поймал намеренно внесённую
ошибку перехвата мыши вне выделения; после проверки исходное условие восстановлено.

Полный `cargo test --workspace` дополнительно проверяет настоящий системный буфер обмена.
Сравнение экранного рендера и экспорта допускает только ±1 в 8-битном канале: Direct2D округляет
сглаженный контур овала при переносе начала координат. Сплошное скрытие проверяется строго побайтно.

## Готово

- DXGI-захват двух мониторов, прогрев, оверлеи, PerMonitorV2 и замеры задержки.
- Выделение мышью, маркеры, клавиатура, привязка к окнам и лупа.
- После выбора целого окна/монитора можно заново обвести маленькую область внутри; вручную нарисованная рамка по-прежнему переносится за середину.
- Панель «Копировать / Сохранить / Сохранить как… / Закрыть».
- Ctrl+C / Enter, Ctrl+S, Ctrl+Shift+S, PNG и отложенный PNG в буфере.
- Разделение на восемь крейтов.
- Чтение `%APPDATA%\Kadr\config.toml`: хоткеи, прогрев, папка сохранения, уведомления.
- Горячее применение конфига по уведомлению файловой системы, без опроса диска в простое.
  Если открыто выделение, изменение откладывается до его закрытия. Ошибка файла сохраняет последние
  действующие настройки. Занятая новая комбинация вызывает откат к прежним настройкам.
- Меню трея с захватом области, монитора, повтором области и открытием настроек в Блокноте.
- Резервный Ctrl+Shift+F12; он не регистрируется отдельно, если уже назначен одному из режимов.
- Существующий установщик с uiAccess, подписью и автозапуском. Установленный exe обновляется отдельно.
- «Недавние»: кадры записываются один раз, выделение обновляется после 300 мс без правок и при закрытии.
  Esc и копирование сохраняют черновик; успешная запись PNG в файл удаляет только соответствующую ревизию.
- Открытие по Ctrl+Alt+PrintScreen, левому клику в трее или пункту «Недавние…».
  Превью с временем, восстановление одним нажатием, Tab/Space/Enter/Esc, очистка с подтверждением.
- После смены мониторов сохранённый рабочий стол вписывается в основной монитор с переносом выделения.
- DPAPI текущего пользователя защищает кадры, превью и документ; открытые временные PNG не создаются.
- Собственная иконка кадра встроена в exe и окна. В трее — прозрачный чёрный/белый знак с выбором
  по системной теме и обновлением при её смене; ICO содержит размеры 16–256 px. Исходники — `assets/icons`.

## Хоткеи по умолчанию

| Комбинация | Действие |
|---|---|
| PrintScreen | Выделить область |
| Shift+PrintScreen | Монитор под курсором сразу в буфер |
| Ctrl+PrintScreen | Видимая область активного окна сразу в буфер |
| Ctrl+Shift+PrintScreen | Последняя выделенная область сразу в буфер |
| Ctrl+Shift+F12 | Резервное выделение области |
| Ctrl+Alt+PrintScreen | Недавние несохранённые снимки |

Быстрые режимы не показывают оверлей, не забирают фокус и не пишутся в «Недавние»: снимок уже в буфере,
а десяток быстрых снимков вытеснил бы несохранённую ручную область. Снимок окна берётся с рабочего стола:
если окно перекрыто другим, перекрывающие пиксели попадут в снимок. «Чистый» захват окна через WGC — позже.
Последняя область хранится до выхода из приложения. При отключении монитора проверяется её доступность.

`[save].folder` — абсолютный путь (относительный конфиг отклоняет) или пустая строка для системной папки «Изображения\Screenshots».
Пустой хоткей отключает назначение; неизвестные поля конфига допускаются, ошибочные и повторяющиеся
комбинации отклоняются. `--warm` / `--cold` имеют приоритет над `capture.warm`.

## Что осталось

1. **M1:** закончить ручную матрицу «Недавних»: сохранение после восстановления, DPI 150/200 %, смена
   раскладки мониторов на живом экране, отказ диска. UI-проверку этой итерации пользователь остановил физическим Escape.
2. **M1:** обычное управление автозапуском из трея, завершение интерфейса и документации.
   Установщик уже включает автозапуск, переключателя в программе пока нет.
3. **M2:** живой UX-проход, дополнительные проверки DPI 150/200 %, HDR/RDP и нескольких GPU.
   Автотесты проверяют логику и невидимый рендер, не заявляют полную доступность для скринридера.
4. **M3/M4:** перенос в чаты, окно настроек, доводка установки, OCR, WGC, HDR и прочее из §15.

При работе над интерфейсом сохранять ранее выбранное направление:
awesome-claude-design (editorial / Vercel grayscale) → ui-ux-pro-max → taste-skill.

- Реальные кадры двух мониторов → PNG 1920×1080. Контрольный прогон из трёх захватов:

## Сборка

```powershell
cargo test --workspace
cargo build --release
```

Для тестов нужен интерактивный рабочий стол Windows. Low-integrity sandbox запрещает захват,
глобальные хоткеи и буфер обмена. При работе в изолированной среде также используйте доступную
папку TEMP: тест наблюдателя проверяет замену уже существующего файла.

Обычная сборка: `target\release\kadr.exe`.
Для обновления установленного режима uiAccess: `cargo build --release --features uiaccess`,
затем существующий `installer\install.ps1` из PowerShell администратора. Скрипт управляет сертификатом,
доверенными хранилищами и автозапуском; проверка сборки не запускает его автоматически.

## Хранение и настройки «Недавних»

```toml
[recent]
enabled = true
max = 10
```

Выключение запрещает создавать новые черновики; прежние остаются до очистки. Сбой/отмена сохранения файла
не удаляют черновик. Завершение старого экспорта не удаляет снимок, уже открытый повторно или изменённый.

Формат v1: `%LOCALAPPDATA%\Kadr\recent\<id>\meta.toml` (только время/статус), `frames.enc`
(неизменяемый набор PNG), `state.enc` (выделение, раскладка, ревизия), `preview.enc` (PNG-превью).
Все `.enc` защищены DPAPI. Метаданные используют уже имеющийся TOML; отдельная JSON/JPEG-зависимость не нужна.
Записи заменяются атомарно через зашифрованный `.part` с `sync_all`. Незавершённая первичная запись в
`.pending-*` не показывается и удаляется при следующем запуске; сбойная запись сразу убирает свой `.part`,
чтобы он не блокировал следующие. Подтверждённый предыдущий вариант состояния сохраняется при прерванной замене.

В debug-сборке `KADR_DEV_INSTANCE=<имя>` позволяет отдельный mutex и делает оверлеи видимыми для нативных
UI-тестов. Для изоляции теста задаются отдельные APPDATA/LOCALAPPDATA и хоткеи. Release всегда единственный
экземпляр; одновременно запускать его со старой Kadr-fixed.exe не нужно.
