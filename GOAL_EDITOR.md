## Доказательства этой итерации

- `tools/check.ps1`: core + app, Clippy workspace; clipboard-тесты не запускаются штатным скриптом, ввод и фокус не меняются.
- `kadr-capture::rotation_tests`: настоящая D3D11-текстура → нормализация 90/180/270 → GPU readback и CPU экспорт, в том числе отрицательные координаты.
- `drawing::tests`: круг → ручка овала, круг номера → отдельная ручка хвоста, ластик как одна операция undo/redo, стили и текстовая выноска.
- `annotations::tests`: фазовое движение пунктира, reduced motion, отсутствие UI в экспорте; варианты текста; лупа не раскрывает оригинал под цензурой; перекрытия blur не возвращают исходные пиксели.
- `ocr::tests::full_censor_detector`: три настоящие строки EN/RU на светлом/тёмном фоне, поиск областей без расшифровки.
- `translate_local::tests::actual_local_models... --ignored`: EN → RU «Скриншот был успешно сохранен», RU → EN «Screenshot successfully saved», без HTTP.
- `installer/test-update.ps1`: shared-progress, временная блокировка, остановка старых имён без сторонних процессов.
- `installer/test-translation.ps1`: распаковка runtime из wheel без pip, SHA256, настоящее inference, повторное использование неизменённого компонента и замена изменённого с резервной копией. Program Files/сертификаты/VC runtime в тесте не изменяются.
- Снимки интерфейса на 100/150/200%: `target/editor-review/final-design`, `target/editor-review/final-setup`.
- Реальный read-only захват без оверлея: `target/editor-review/capture/capture.txt`. Сейчас обе системы DXGI сообщают rotation=1 (горизонтально), поэтому живой вертикальный экран этим не подтверждён.
- Цензура 100 областей, release offscreen: подготовка слоя 104.581 мс (фон), upload до анимации 1.931 мс; p95 кадра 1.834 мс, max 2.450 мс. Холодный первый кадр всей сцены 16.147 мс учитывается отдельно. Это не реальный input-to-photon.

## Остаётся проверить на установленной версии

- Повторные реальные снимки на физически вертикальном втором мониторе и отсутствие затемнения собственной предыдущей сессии. Исправления уже в коде: поворот до размещения, DWM-barrier после скрытия и сброс очереди старого дубликатора; при ошибке захвата старые пиксели не показываются.
- Ощущение задержки и полнота автоцензуры на исходном Telegram-примере пользователя. В коде исправлено перекрытие масок, добавлены detector-only Full + второй проход, кэш OCR Light/Hard, ограничение памяти кэша и покрытие переполнения лимита областей. Автоматический детектор не считается безошибочным по одному синтетическому тесту.
- [x] Финальная упаковка uiAccess и сверка payload: dist/verification.json. Setup, скрипт, manifest, worker, OCR и восемь языковых assets сверены. Физические сценарии выше остаются открытыми.


## Дополнительный переносимый пакет

`installer/package-translation.ps1` создаёт `dist/Kadr-Offline-EN-RU.zip` (416 417 187 байт).
Если распаковать его `translation-downloads` рядом с `Kadr-Setup.exe`, установщик берёт
компоненты локально, сверяет SHA256 и не обращается к сети. Без папки скачивает их один раз;
при неизменённом уже установленном компоненте повторной загрузки нет. Системный Python не нужен.
