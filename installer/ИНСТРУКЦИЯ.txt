KADR — УСТАНОВКА НА ДРУГОЙ КОМПЬЮТЕР
====================================

Что нужно
---------
• Windows 10 или 11, 64-бит.
• Учётная запись с правами администратора (один раз, на установку).
• Больше ничего: всё нужное уже внутри kadr.exe.


Установка (≈1 минута)
---------------------
1. Перенесите архив Kadr-setup.zip на второй компьютер (флешка, облако, мессенджер — любой способ).

2. Распакуйте его: правый клик → «Извлечь всё…». Папку можно положить куда угодно,
   например на Рабочий стол. Запускать прямо из архива нельзя — сначала распакуйте.

3. В распакованной папке дважды щёлкните «Установить.cmd».
   Windows спросит «Разрешить этому приложению вносить изменения?» → «Да».

4. Откроется синее окно PowerShell. Дождитесь строки «Готово» и закройте его.
   Если на компьютере нет распознавания текста, установщик скачает его (английское и
   русское) — с интернетом это пара минут.
   Kadr запустится сам — значок появится в трее (у часов, возможно под стрелкой ^).

5. Проверьте: нажмите PrtSc — экран затемнится, можно выделять область.

Папку с установщиком после этого можно удалить: программа живёт в
C:\Program Files\Kadr и запускается вместе с Windows.

Как открыть снова, если вышли из Kadr: меню «Пуск» → Kadr.
Файл kadr.bin в папке установщика — это сама программа для установки; запускать его не нужно
(Windows разрешает Kadr работать только из Program Files, отсюда ошибка «Сервер возвратил ссылку»).


Что делает установщик
---------------------
• Создаёт на ЭТОМ компьютере собственный сертификат подписи «Kadr Local Code Signing»
  и подписывает им kadr.exe. Закрытый ключ создаётся здесь же и никуда не уходит,
  с первого компьютера ничего секретного не переносится.
• Копирует программу в C:\Program Files\Kadr — Windows даёт «uiAccess» (снимки поверх
  окон администратора, например Диспетчера задач) только подписанным программам оттуда.
• Включает автозапуск, кладёт ярлык Kadr в меню «Пуск» и запускает Kadr с обычными правами.
• Докачивает распознавание текста Windows для английского и русского, если его нет.


Если что-то пошло не так
------------------------
• «Windows защитила ваш компьютер» при запуске Установить.cmd →
  «Подробнее» → «Выполнить в любом случае». Так бывает, если архив пришёл из интернета.

• PrtSc открывает «Ножницы» Windows, а не Kadr →
  Параметры → Специальные возможности → Клавиатура →
  выключите «Использовать кнопку Print Screen для открытия функции "Ножницы"»,
  затем перезапустите Kadr (трей → правый клик → Выход, и запустите из меню «Пуск» → Kadr).

• «Текст», «Перевод» или «Цензура» ничего не находят → распознавание не докачалось
  (в синем окне было предупреждение). Подключите интернет и запустите «Установить.cmd»
  ещё раз — он докачает только недостающее.

• Перевод работает только с интернетом. Отправляется лишь распознанный текст,
  картинки компьютер не покидают.

• Журнал работы: %LOCALAPPDATA%\Kadr\logs\kadr.log (вставьте путь в адресную строку Проводника).


Настройки
---------
Свои настройки на первом компьютере вы не меняли, поэтому здесь всё будет так же.
Если поменяете — они в %APPDATA%\Kadr\config.toml; этот файл можно просто скопировать
на другой компьютер в ту же папку.
«Недавние» снимки не переносятся: они зашифрованы ключом Windows конкретного компьютера.


Обновление
----------
Новая версия приходит такой же папкой — снова запустите «Установить.cmd».
Установщик сам остановит старый Kadr и заменит его.


Удаление
--------
Дважды щёлкните «Удалить.cmd» → «Да». Удалятся программа, автозапуск и сертификат.
