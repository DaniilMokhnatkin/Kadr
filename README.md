# Kadr

Личный скриншотер для Windows на Rust: выделение, аннотации, текст, размытие, PNG/буфер обмена
и восстановление несохранённых снимков. Основная папка проекта: `C:\Users\r4pto\Documents\kadr`.

- `STATUS.md` — готовые функции, хоткеи, проверки и оставшаяся работа.
- `M2.md` — границы редактора и способы проверки.
- `SESSION_SUMMARY.md` — результат диалога от 29 октября 2026 и точки продолжения.
- `ARCHITECTURE.md` — архитектура и исходный расширенный план; фактическое состояние смотреть в STATUS.
- `crates/` — все восемь крейтов с исходниками и тестами.
- `assets/icons/` — SVG, ICO, PNG, лист проверки и генератор иконок.
- `manifests/`, `installer/` — обычный/uiAccess-манифесты и установщик.
- `dist/Kadr.exe` — сохранённая готовая сборка; бинарник не отслеживается Git.

## Запуск и сборка

Перед запуском новой копии завершите прежний Kadr через меню трея: приложение работает в одном экземпляре.

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release
```

Проверка M2 без окон, курсора и фокуса:

```powershell
powershell -File tools/check-m2.ps1
```

После выделения выбирайте инструмент на панели или клавишей: A — стрелка, T — текст, B — размытие,
X — скрытие, V — выбор фигур. Ctrl+Z / Ctrl+Y — отмена/повтор, F2 — правка текста.

Нужны Windows, Rust MSVC и Windows SDK с `rc.exe`. Иконки уже сгенерированы и включены в сборку;
Python для обычной компиляции не требуется. Тесты буфера обмена и DPAPI выполняются в обычном
интерактивном окружении Windows. В ограниченной песочнице часть Win32-функций недоступна.

Проверка ресурсов иконок без запуска приложения (Python + Pillow):

```powershell
python tools/verify_icon_resources.py
```

По умолчанию проверяется `dist/Kadr.exe`; другой exe можно передать первым аргументом.
Обычная сборка запускается без uiAccess. Для установленного uiAccess-варианта см. `installer/install.ps1`
и описание в STATUS; этот скрипт управляет сертификатом и запускается пользователем от администратора.

В полном резервном архиве также находится `history.bundle` с историей Git. Её можно восстановить командой
`git clone history.bundle Kadr-restored`. В основной папке проекта история уже находится в `.git`.
