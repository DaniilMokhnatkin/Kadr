# Kadr

Скриншотер для Windows на Rust: быстрый, с собственным плавным интерфейсом и всем, что нужно,
чтобы снять экран, пометить важное, скрыть лишнее и отправить.

## Что умеет

- **Снимок за ~8 мс** по PrtSc: область, монитор под курсором, активное окно, прошлая область.
  Работает поверх любых окон, включая окна администратора (uiAccess).
- **Редактор прямо на экране**: стрелки, рамки, овалы, карандаш, маркер, ластик, лупа, текст
  с фоном и выноской, нумерация, размытие, затемнение вокруг, заливка.
- **Цензура** в один клик: находит почты, телефоны, номера карт и размывает их (лёгкая, жёсткая
  и полная — весь текст). По желанию — автоматически перед каждым копированием.
- **Текст с экрана**: Ctrl+Shift+C копирует распознанный текст (PaddleOCR внутри Kadr или
  распознавание Windows), а QR-код — его содержимое со ссылкой «Открыть».
- **Перевод** выделенного текста: офлайн EN ↔ RU на этом компьютере или через Google.
- **Запись экрана** в MP4 со звуком или в GIF для чатов.
- **Миниатюра в углу** после снимка: перетащите в чат или откройте, чтобы дорисовать и обрезать.
- **Буфер обмена по Win+V** вместо системного: история того, что копировали (текст, картинки,
  файлы), поиск, закрепление, хранится зашифрованно и после перезагрузки; кнопка «Снимки»
  открывает «Недавние».
- **Закрепление** снимка поверх окон, **«Недавние»** — зашифрованная история до 25 несохранённых снимков.
- Лупа с цветом пикселя (клавиша C копирует HEX), светлая и тёмная темы, обновления из GitHub.

## Установка

Скачайте `Kadr-Setup.exe` со страницы [Releases](../../releases) и запустите. Установщик спросит,
каким распознаванием текста пользоваться и нужен ли офлайн-перевод, один раз попросит права
администратора и поставит Kadr в `Program Files` с автозапуском. Обновления Kadr находит сам,
проверить вручную можно из меню значка в трее.

Нужна Windows 10 или 11 (x64).

## Сборка из исходников

Нужны Rust (MSVC) и Windows SDK с `rc.exe`.

```powershell
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
cargo build --release
```

Установщик целиком (uiAccess-сборка, PaddleOCR и офлайн-перевод скачиваются скриптами с
проверкой SHA-256):

```powershell
powershell -ExecutionPolicy Bypass -File installer\fetch-ocr.ps1
powershell -ExecutionPolicy Bypass -File installer\build-release.ps1 -Tag v1.0.0
```

Готовый `dist\Kadr-Setup.exe` содержит программу, скрипт установки и PaddleOCR. Чтобы собранный
Kadr проверял обновления, адрес репозитория задаётся в `.cargo/config.toml`; для своей копии
можно переопределить его переменной `KADR_REPO` до сборки.

Для следующего релиза: измените версию в `Cargo.toml`, запустите сборку с совпадающим тегом
`vX.Y.Z` и опубликуйте в GitHub обычный release с файлом `Kadr-Setup.exe`. Установленная
версия проверяет новый тег и обязательную контрольную сумму GitHub перед запуском установки.
`build-release.ps1` проверяет соответствие тега и версии; тесты и Clippy запускайте перед публикацией.

Для автоматического выпуска отправьте в GitHub новый тег `vX.Y.Z` на коммите с такой
версией. Workflow `Release Kadr` проверит и соберёт программу, загрузит установщик
в черновик и опубликует релиз после сверки размера и SHA-256. Порядок выпуска —
[RELEASING.md](RELEASING.md).

Фоновая проверка без видимых окон и движения курсора: `powershell -File tools/check.ps1`.
Замер без рабочего стола: `target\release\kadr.exe --interaction-bench result.txt`.

## Клавиши в редакторе

A — стрелка, T — текст, B — размытие, X — скрытие, V — выбор, Tab — следующий инструмент,
1–6 — цвет, [ ] — толщина. Ctrl+Z / Ctrl+Y — отмена/повтор, F2 — правка текста,
Ctrl+C — копировать, Ctrl+S — сохранить, Ctrl+D — закрепить, Ctrl+H — «Недавние»,
Ctrl+Shift+C — текст или QR-код, Ctrl+T — перевод, C (до выделения) — цвет пикселя.

## Устройство проекта

- `crates/` — крейты: захват (DXGI), документ и аннотации, редактор, отрисовка (Direct2D),
  экспорт, хранилище и настройки, Win32-обвязка, приложение и установщик.
- `installer/` — скрипты установки, упаковки и загрузки компонентов распознавания и перевода.
- `assets/icons/`, `manifests/` — иконки и манифесты (обычный и uiAccess).
- `ARCHITECTURE.md`, `STATUS.md`, `DESIGN.md`, `MOTION.md`, `PERFORMANCE.md`, `M2.md`, `M3.md` —
  архитектура, состояние, дизайн, анимации, замеры и заметки по этапам.

## Сторонние компоненты

PaddleOCR (модели, Apache-2.0) и ONNX Runtime (MIT) — см. `installer/NOTICE-ocr.txt`.
Офлайн-перевод: CTranslate2 (MIT), SentencePiece (Apache-2.0) и модели Argos Translate,
скачиваются установщиком по списку `installer/translation-manifest.json`.
